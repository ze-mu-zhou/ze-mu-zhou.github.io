# ze-mu-zhou.github.io

我的个人主页，基于 [al-folio](https://github.com/alshedivat/al-folio) 主题（MIT License，见 `LICENSE`）。

在线访问：**https://ze-mu-zhou.github.io**

## 更新方式

- 主页简介与板块：编辑 `_pages/about.md`
- 动态（News）：在 `_news/` 下添加 `announcement_*.md`
- CV 页结构化数据：编辑 `_data/cv.yml`
- 社交链接：编辑 `_data/socials.yml`
- 站点/个人信息：编辑 `_config.yml`

push 到 `main` 后由 GitHub Actions 构建并发布到 `gh-pages` 分支（Pages 源为 gh-pages），约 2-3 分钟生效。

历史：2026-07-26 从 AcadHomepage 模板迁移至 al-folio（见 `docs/superpowers/specs/`）。
