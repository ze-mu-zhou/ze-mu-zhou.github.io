# ze-mu-zhou.github.io

我的个人主页，基于 [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) 模板（MIT License，见 `LICENSE`）。

在线访问：**https://ze-mu-zhou.github.io**

## 更新方式

- 主页内容：编辑 `_pages/about.md`
- 站点/个人信息：编辑 `_config.yml`
- 导航栏：编辑 `_data/navigation.yml`

push 到 `main` 后 GitHub Pages 自动重新构建，约 1 分钟生效。
